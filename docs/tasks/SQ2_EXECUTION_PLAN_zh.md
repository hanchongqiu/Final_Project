## 1. 恢复数据，复核基线

仓库已有公共读取、训练、推理和评估代码、五种子基线表、SQ3 结果及报告框架。第 4 节待完成。在服务器 clone `feat/sq2-label-noise` 后，从仓库根目录执行以下命令。需要 Linux、Bash、curl、unzip、sha256sum 和 uv。

```bash
bash scripts/prepare_sq2_data.sh
uv sync --locked --python 3.12 --extra dev
uv run python scripts/verify_env.py
uv run pytest -q
```

准备脚本使用作业第 5 页的 Dropbox 下载地址，从[组内 Google Drive](https://drive.google.com/drive/folders/15fq-wqkoYzu7fROPwWg5qLtmWuLfhcKd?usp=sharing) 下载三份基线文件，逐个与本地已核验副本比对 SHA-256。已校验的下载会复用。可用环境变量 `SQ2_IMAGE_URL` 指定组内提供的 Dropbox 直链（`dl=1`）。若服务器无法访问网盘，也可将现有 `img_data.zip` 放入 `data/`，把本地的 `outputs-*.zip` 解到仓库根目录，再执行相同命令。

- 图像包自带 `monthly_20d/`，解压后是 `data/monthly_20d/`，共 27 对 `.dat` 与 `.feather`。逐年验证图像字节数等于标签行数 × 64 × 60，合计 2,196,994 行。使用现有 `np.memmap` 和批内归一化。
- 成果包自带 `outputs/`，有 `predictions/baseline_seed42.parquet`、`checkpoints/baseline_seed42.pt`、`predictions/baseline_ensemble5.parquet`。以第一份文件充当 C0。已逐年核对其 `(year,row_idx)` 与真实标签，并从概率复算 Accuracy、CE。执行时用公共评估器核对整行表 1：**52.33225%、CE 0.692360、AUC 0.532183、ECE 0.016573、多空 Sharpe 1.696175**。单种子基线用于全部主对照。若需重建预测，加载已有最佳权重做推理。
- 在 NVIDIA 服务器确认自检报告 CUDA 及实际 GPU 名称；若显示 CPU，先核查 GPU 是否分配给当前作业、驱动与 PyTorch 是否匹配。随后跑通小批训练、推理、存表，用一个正式 epoch 估时。历史基线 seed 42 的 12 轮训练与验证合计 **47.8 分钟**，另需样本外推理。

实现 `experiments/exp_sq2_label_noise.py`，按实验编号独立运行，可从已有预测重建表与图。共 **1 个已有对照，7 次新训练**。调用 `build_train_val_test_splits`、`CNN20D`、`train_model`、`predict_dataset` 和 `save_predictions`。固定训练与划分 seed 42、Adam 学习率 1e-5、batch 256、最多 15 轮、patience 2。C1–C7 在构建模型前调用 `seed_everything(42)`，每组从头训练。原基线脚本在建模后才设训练种子，故 C0 用已交付预测，不宣称两边初始权重完全一致。

## 3. 评估与解释

1. **保留可复算的预测。** 每组保存标准样本外 Parquet，C6、C7 同时保留本周期 `Ret_{h}`、`Retx_{h}`。记录训练数、保留率、训练正例率、验证与测试数、最佳 epoch。检查主键唯一、概率有限且在 [0,1]、标签与图像行对齐。每组结束便落盘，以已有预测重画图时无需重训。
2. **区分三类结果。** 同时报告 Accuracy、交叉熵（CE）、AUC、10 箱 ECE，以及各调仓日按上涨概率排序后、等权最高十分位减最低十分位的收益和 Sharpe。CE 衡量概率预测损失，AUC 衡量排序，ECE 衡量可信度；按公共代码，ECE 的标量使用预测类别置信度。C5 用**硬标签**计算验证和测试 CE。比较 C0 与 C5 的 CE/ECE，再看排序和收益是否同向。20d 过滤曲线同时给出保留率，并按 C0 训练池的市值分组展示各组保留率，检查过滤改变了哪些股票的权重。
3. **修正跨周期收益回退。** `evaluate_predictions` 默认调用的组合函数会用 `Retx_20d` 填缺，即使传入 5d/60d 的 `ret_col`。5d、60d 有效测试集的含息收益分别缺 1,218、1,214 条。保留原始预测列；在评估副本中先用**同周期** `Retx_{h}` 填好 `Ret_{h}`，断言有效样本填补后无缺失，再指定 `ret_col` 调公共评估器。用 `compute_decile_portfolio` 的同周期 `fallback_ret_col` 取逐月 `ls_ret`，核对汇总值。测试中放入一条各周期收益不同的缺失样本，验证回退逻辑。
4. **公平比较周期。** 主表报告各自完整测试集；再按 `(year,row_idx)` 对齐 C6/C0/C7，在共同的 **1,471,746** 张图上复算三组指标。各组始终使用自己的标签、概率与收益。并列各周期上涨占比，辅助解读 Accuracy。主图展示各期平均多空持有期收益，标清 5/20/60 个交易日。公共 Sharpe 按月度观测统一乘 √12；5d 只有每月一次信号，60d 相邻持有期重叠，因此跨周期的 Sharpe 仅作描述，不能直接解释为可实施策略的优劣。
5. **用结果回答假设。** 写出 C2 相对 C0 的 AUC/Sharpe 差值、C5 相对 C0 的 CE/ECE 差值，以及共同样本上三周期的实际顺序。把全套阈值都列出。固定阈值同时改变样本量和构成，C4 的保留率也明显高于 C1–C3；这些差异限制因果解释。单种子小差异只作描述。若要陈述某项改善显著，可对同一批月份成对做连续月份分块重采样，并报告差值区间。60d 前瞻窗口可能跨越 1999/2000 分界，解释时说明切分以图像日期为准。
